# Demo

## Grundlegende Git-Befehle

### Repository klonen
```bash
git clone <repository-url>
```

### Status anzeigen
```bash
git status
```

### Änderungen prüfen
```bash
git diff
```

### Dateien zum Commit hinzufügen
```bash
git add <dateiname>
git add .
```

### Änderungen committen
```bash
git commit -m "Beschreibung der Änderung"
```

### Commit-Verlauf anzeigen
```bash
git log
```

### Branches anzeigen
```bash
git branch
```

### Neuen Branch erstellen
```bash
git checkout -b <branch-name>
```

### Zu einem Branch wechseln
```bash
git checkout <branch-name>
```

### Änderungen von einem Branch übernehmen
```bash
git merge <branch-name>
```

### Änderungen vom Remote laden
```bash
git pull
```

### Änderungen zum Remote senden
```bash
git push
```

### Remote-Verbindungen anzeigen
```bash
git remote -v
```

### Repository initialisieren
```bash
git init
```

### Dateien aus dem Index entfernen
```bash
git restore --staged <dateiname>
```

### Änderungen verwerfen
```bash
git restore <dateiname>
```

### Hilfe zu Git-Befehlen
```bash
git help <befehl>
```
